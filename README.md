# ⚔️ 피파 전쟁 봇

`/전쟁 상대:@친구` 한 방이면 상대한테 DM이 가고, 게임방 채널에 사이렌이 울린다.
수락 → 경기 → 스코어 입력 → 상대 확인 → 리그 순위표 반영. **Render 무료 플랜**에서 24시간 돌아가게 만들어 둠.

- 🚨 전쟁 선포: 상대 DM(“A님이 B님한테 축구 전쟁을 걸었습니다”) + 경보 채널 핑 + 수락/도망 버튼
- 📝 결과 입력: 스코어 모달 → 상대가 ✅확인 / ⚠️이의제기 (10분간 이의 없으면 자동 확정 → 패배자가 버텨도 소용없음)
- 🏆 리그: 승 3 · 무 1 · 패 0 → 승점 · 득실차 · 다득점 순위, 칭호 승급, 연승/연패 속보, 천적·먹잇감, 도망 횟수
- 🌐 웹 순위표: `https://<서비스이름>.onrender.com` — 흑백 전광판 디자인. 마지막 경기 스코어와 승점이 플립 숫자로 넘어가고, 20초마다 자동 갱신(순위 바뀌면 줄이 미끄러지며 ▲▼ 표시). 우측 상단 버튼으로 흰 화면/검은 화면 전환
- 💾 전적 백업: 서버 안 숨김 채널 `#fifa-war-db` 에 자동 저장 → 재배포·재시작해도 기록 유지 (외부 DB 가입 필요 없음)

## 1. 디스코드 봇 만들기

1. <https://discord.com/developers/applications> → **New Application**
2. **Bot** 탭 → **Reset Token** → 나온 토큰 복사 = `DISCORD_TOKEN`
3. (선택) 같은 Bot 탭에서 **MESSAGE CONTENT INTENT** 켜기
   → 켜면 `@친구 피파전쟁` 텍스트 명령도 됨. 안 켜도 봇이 알아서 슬래시 명령 전용으로 뜸 (예전 `Used disallowed intents` 오류 안 남)
4. **초대** — `<애플리케이션ID>` 는 General Information 탭에 있음:

```
https://discord.com/oauth2/authorize?client_id=<애플리케이션ID>&scope=bot%20applications.commands&permissions=248912
```

`248912` = 채널 관리(백업 채널 생성) · 메시지 보내기 · 링크/파일 첨부 · 기록 보기 · 반응 · @everyone 멘션(경보 역할 핑)

## 2. GitHub 에 올리기

새 레포 만들고 이 폴더 통째로 업로드 (`node_modules` 는 `.gitignore` 로 빠짐).

## 3. Render 배포 (무료)

**방법 A — Blueprint (추천)**
Render → **New → Blueprint** → 레포 선택 → `DISCORD_TOKEN` 입력 → **Apply**

**방법 B — 직접**
**New → Web Service** → 레포 선택

| 항목 | 값 |
|---|---|
| Runtime | Node |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Instance Type | **Free** |
| Environment | `DISCORD_TOKEN` = 봇 토큰 (따옴표 없이) |

> ⚠️ **Background Worker 말고 Web Service** 로 만들어야 무료. (워커는 무료 플랜이 없음)

로그에 `✅ ... 로그인` 이 뜨면 끝. `https://<서비스이름>.onrender.com` 열면 순위표가 보인다.

## 4. 디스코드에서 첫 설정

```
/피파설정 경보채널:#게임방          ← 경보 울릴 채널 (관리자만)
/피파설정 경보역할:@피파            ← (선택) 경보 때 역할도 같이 핑
/전쟁 상대:@친구                    ← 전쟁 시작!
```

## 명령어

| 슬래시 | 텍스트 (INTENT 켰을 때) | 설명 |
|---|---|---|
| `/전쟁 상대:@친구` | `@친구 피파전쟁` | 전쟁 선포 (DM + 경보) |
| `/전적 [유저]` | `피파전적` · `@친구 피파전적` | 전적 카드 (칭호·순위·연승·최근 5경기·천적) |
| `/상대전적 상대:@친구` | `@친구 상대전적` | 맞대결 기록 + 최근 맞대결 |
| `/랭킹` | `피파랭킹` | 리그 순위표 TOP 10 (+ 웹 순위표 링크) |
| `/도움말` | `피파도움말` | 사용법 |
| `/피파설정` | — | 경보 채널·역할, 저장소 상태, 권한 점검 (관리자) |

## 전쟁 흐름

```
선포 ──▶ 상대 DM + 🚨경보 ──▶ [⚔️ 수락] ──▶ ⚽ 경기 ──▶ [📝 결과 입력] 3:1
            │                    │                              │
            │ 5분 무응답 → 무산   └ [🏳️ 도망] → 도망 횟수 +1       ▼
            │                                         상대: [✅ 확인] → 🏁 확정 + 📢속보
            │                                               [⚠️ 이의제기] → 다시 입력
            └ 경기 3시간 동안 결과 없으면 무효            10분 무응답 → ⏱️ 자동 확정
```

- 한 사람은 동시에 전쟁 하나만 (도배 방지 쿨다운 20초)
- 버튼은 당사자만 누를 수 있고, 결과 제출한 사람은 셀프 확인 불가

## Render 무료 플랜에서 알아둘 것

- **잠들기 방지** — 무료 웹서비스는 15분간 접속이 없으면 잠든다. 봇이 10분마다 자기 주소(`RENDER_EXTERNAL_URL`, Render가 자동 설정)로 핑을 보내서 안 잠듦.
  더 확실히 하려면 [UptimeRobot](https://uptimerobot.com) 같은 곳에서 `https://<서비스이름>.onrender.com/health` 를 5분 간격으로 모니터링 추가.
- **무료 시간 월 750시간** = 서비스 1개를 한 달 내내 켜두는 분량. 같은 Render 계정에 다른 무료 웹서비스도 24시간 돌리면 월말에 둘 다 멈춘다.
- **디스크는 재시작 때 초기화** → 그래서 전적을 `#fifa-war-db` 채널에 백업함. **이 채널/메시지는 지우지 말 것.** (봇한테 채널 관리 권한 필요, 최근 백업 5개 보관)

## 환경변수

| 키 | 필수 | 설명 |
|---|---|---|
| `DISCORD_TOKEN` | ✅ | 봇 토큰 |
| `ALERT_CHANNEL_ID` | | 기본 경보 채널 (`/피파설정` 값이 우선) |
| `ALERT_ROLE_ID` | | 경보 때 핑할 역할 |
| `DATA_CHANNEL_ID` | | 백업 채널 직접 지정 (기본: `#fifa-war-db` 자동 생성) |
| `BOARD_PUBLIC` | | `false` 면 웹 순위표 숨김 (기본 `true`) |
| `TEXT_COMMANDS` | | `false` 면 텍스트 명령 끔 (기본 `true`) |

## 문제 해결

| 증상 | 해결 |
|---|---|
| 로그에 `TokenInvalid` / 순위표 페이지에 토큰 오류 | Bot 탭 → Reset Token → 새 토큰을 `DISCORD_TOKEN` 에 따옴표 없이. (Client Secret·Application ID 넣으면 로그에 그렇다고 알려줌) |
| 슬래시 명령이 안 보임 | 초대 링크에 `applications.commands` 포함됐는지 확인 → 디스코드 앱 `Ctrl+R` |
| 텍스트 `@친구 피파전쟁` 무반응 | MESSAGE CONTENT INTENT 켜고 Render 대시보드에서 **Manual Deploy** (재배포) |
| 경보가 안 울림 / 역할 핑이 안 감 | `/피파설정` 실행 → 아래 **⚠️ 확인 필요** 에 빠진 권한이 나옴 |
| 봇이 두 번씩 반응 | 예전 피파 봇이 같은 토큰으로 다른 곳(예: 예전 Background Worker)에서 아직 돌고 있음 → 그쪽 중지 |
| 로그에 `로컬 저장만` | 봇에 **채널 관리** 권한 주고 재시작 (또는 `DATA_CHANNEL_ID` 지정) |
